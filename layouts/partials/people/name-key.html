{{- /* Comparison key for a person's name. Event hosts (from Ticket Tailor) and people profiles (hand-authored) are two different sources that don't agree on honorifics: the same person can be "Dr. Jessica Hutchings" on one side and "Jessica Hutchings" on the other. Matching on the raw title silently drops those links, so every name → profile lookup goes through this key instead: lowercased, every kind of space folded to a plain one and collapsed, and a leading honorific ("Dr", "Dr.", "Prof", "Ms", …) removed — so "Dr. Ana Lopez", "Dr Ana Lopez" and "Ana Lopez" all resolve to the one profile. The space folding is not cosmetic: Ticket Tailor's rich text editor writes "Dr. Ana Lopez", and Go's regexp `\s` — unlike JavaScript's — does not match a non-breaking space, so without \p{Zs} the honorific would sit behind a space this key can't see and the name would never match. Only the key is normalised — pages still display their own title, so whoever wrote "Dr" keeps their "Dr". Takes a name string, returns the key. Mirrored in scripts/build-programme.mjs (nameKey, HONORIFICS and SPACES) — change them together. */ -}} {{- $name := lower (printf "%v" (. | default "")) -}} {{- $name = replaceRE `[\s\p{Zs}\x{feff}]+` " " $name -}} {{- $name = replaceRE `^ *(?:dr|prof|professor|mr|mrs|ms|mx|rev|fr|sir|dame|hon)\.? +` "" $name -}} {{- return (trim $name " ") -}}
