{{- /* Home — Upcoming Events: the next N events from the programme (soonest first, dateTBC/past events excluded), grouped by date the same way the programme list is (date heading, then each event on that day — no dividers, unlike the programme list), plus a link through to the full programme. N is read from the front matter of the page calling this partial (`upcomingEventsCount`), defaulting to 4. A recurring event (front matter `dates:`) appears once here, dated by its next session — unlike the programme list, which shows it on every day it runs. "Today" is fixed at build time, so if the nightly rebuild (deploy.yml) doesn't happen, events that have since passed would linger. To cover that, $spare more occurrences are rendered after the first N, `hidden`, every session of a recurring event included, and the script below re-picks the next N against the viewer's clock in Wellington time: dropping past days, skipping repeat sessions, unhiding spares to fill in. Without JS the markup shows exactly what the build chose. */ -}} {{- $n := .Params.upcomingEventsCount | default 4 -}} {{- $spare := 30 -}} {{- $events := where .Site.RegularPages "Section" "programme" -}} {{- $today := (partial "now-nzt.html" .).Format "2006-01-02" -}} {{- $upcoming := slice -}} {{- range partial "programme/occurrences.html" $events -}} {{- if and (not .page.Draft) (ge .day $today) -}} {{- $upcoming = $upcoming | append . -}} {{- end -}} {{- end -}} {{- with $upcoming -}} {{- $groups := partial "programme/group-occurrences.html" (first (add $n $spare) .) -}} {{- /* Decide, in render order, which items the build itself shows: the first session of each of the first N events. */ -}} {{- $seen := slice -}} {{- $shown := dict -}} {{- range $gi, $g := $groups -}} {{- range $pi, $p := $g.pages -}} {{- if and (lt (len $seen) $n) (not (in $seen $p.RelPermalink)) -}} {{- $seen = $seen | append $p.RelPermalink -}} {{- $shown = merge $shown (dict (printf "%d-%d" $gi $pi) true) -}} {{- end -}} {{- end -}} {{- end -}}
