Everything below this header is the signed-off prototype from signage-kit/event.html, carried across unchanged except for the EVENTS array, which Hugo generates from content/programme/. ================================================================== */ -}} {{- $tz := "Pacific/Auckland" -}} {{- /* QR codes are generated at build time and inlined as data URIs. They must not become files in /public — the panel cannot fetch anything. `.Content | base64Encode` is what keeps them inside the document. Hugo caches by input, so a recurring event costs one QR, not one per date. $signBase is hardcoded rather than taken from Permalink on purpose. Permalink follows baseURL, so under `hugo server` — which is how this board is served to the panel over the LAN — every code would encode http://192.168.x.x:1313/... and be worthless to anyone scanning it. The phone doing the scanning is on the internet, not the venue network, so the code must always carry the public address regardless of where the page itself is being served from. */ -}} {{- $signBase := "https://criticalsignals.nz" -}} {{- /* Printed on the board without the scheme — nobody types "https://" into a phone, and dropping it leaves room for the web icon beside it. Static, so the codes stay byte-identical whatever baseURL the page is built with. */ -}} {{- $signUTM := "?utm_source=window_sign" -}} {{- $qrOpts := dict "level" "medium" "scale" 4 -}} {{- $siteQR := printf "data:image/png;base64,%s" (((images.QR (printf "%s/%s" $signBase $signUTM) $qrOpts).Filter images.Invert).Content | base64Encode) -}} {{- /* Host photos. Same resolution rule as the rest of the site — hosts are written as names, `people/by-name.html` maps a name to that person's profile page (honorific-insensitive), and `feature-image.html` finds that page's photo. A host with no profile, or a profile with no photo, simply contributes nothing. Squared off and inlined as a data URI for the same reason as the QR codes: the panel cannot fetch anything, so a `` would be a hole on the wall. The size tracks what the photo renders at in portrait — the panel is 1:1, so anything larger is bytes on the wire for nothing, and anything smaller is a soft photo. jpeg q72 keeps each face under 10KB before base64; they are deduplicated below. */ -}} {{- $people := partialCached "people/by-name.html" . -}} {{- $faceSpec := "229x229 Center jpg q72" -}} {{- /* Emit generously and let the browser choose. Counting by title catches both. */ -}} {{- $seriesCount := dict -}} {{- range $onSign -}} {{- $k := lower (replaceRE `\s+` " " (trim .page.Title " ")) -}} {{- $seriesCount = merge $seriesCount (dict $k (add (int (index $seriesCount $k | default 0)) 1)) -}} {{- end -}} {{- /* The whole season, past dates included, so the board can say how far through it we are.
